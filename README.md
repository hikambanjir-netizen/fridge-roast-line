One line, 77 characters, roasting a smart fridge — its firmware update asked for a rating, and the fridge did not take the one star well.

> My fridge asked me to rate its firmware update. I gave it one star. It froze.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (1–200 UTF-8 characters, as the gate requires). Pure Python standard library, no dependencies.
